# Спонтанният ред — landing page

Статична едностранична страница за QR кода от флаерите. Без build стъпка, без tracking, без cookies.

Адрес: https://imebg.github.io/spontanniat-red/

```
index.html            страницата
styles.css            всички стилове
assets/logo.svg       логото на подкаста (изрязано до кръга, без бял фон)
assets/ime-logo.png   логото на ИПИ (бяло, прозрачен фон)
favicon.svg           favicon
apple-touch-icon.png  икона при „Добави към началния екран“ (180×180)
og-image.png          изображение при споделяне (1200×630)
```

Шрифтове: Oswald (заглавия, бутони) и Golos Text (текст), от Google Fonts.

## Публикуване (GitHub Pages)

1. Публично хранилище `imebg/spontanniat-red`.
2. Add file → Upload files → всички файлове и папката `assets` → Commit changes.
3. Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.

Промяна по-късно: качете новите файлове на същото място. Адресът и QR кодът не се променят.
